# Changelog

## v0.1.1 - 2026-11-20

First public release. The Mac app, notarized, with a 30-day trial key. Requires macOS 27 or later (Apple silicon).

- On-device work log: frontmost-app sessions and file activity in folders you choose, with time away not counted.
- Journal window: sidebar of days, active time, summary, time per app, timeline and files touched.
- Summaries: template, or Apple's on-device model on click where available.
- Exports: Markdown, timesheet CSV and files CSV.
- AES-256-GCM day files with the key in the Keychain; sandboxed with no network entitlement.
- Soft licence status: never disables a feature. Free 30-day trial key: sales@zyvor.dev.

An internal 0.1.0 build was never published.
